# SJEC Course File Automation

A web-based Course File Automation System designed for St Joseph Engineering College (SJC).

## About the Project

Course File Automation aims to simplify and digitize the process of maintaining academic course files.

Currently, course-related information such as student marks, assignments, course outcomes and other academic records is maintained using multiple Excel sheets and documents.

This project aims to bring these activities into a centralized web-based application backed by a relational database.

## Project Objectives

- Centralize academic and course-related information.
- Maintain faculty, student and course records.
- Store assessment marks in a structured database.
- Simplify course-file management.
- Reduce manual data handling and duplication.

## Planned Modules

### 1. Database Management System
- Faculty management
- Student management
- Course management
- Academic year and course instance management
- Assessment and marks storage

### 2. Computation
- Marks calculation
- Course Outcome (CO) attainment
- Program Outcome (PO) and Program Specific Outcome (PSO) attainment

### 3. Excel Generation
- Downloadable marksheets
- Course-file reports
- Academic reports
